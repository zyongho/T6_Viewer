# 버전 기록

## 다음 버전 계획
- 클립 내보내기: 목록에서 클립 여러 개를 골라 우클릭 → 내보내기 창에서 카메라·시간 구간 선택,
  하나로 이어 붙이기(기본) 또는 카메라별 파일, 주행 정보(HUD)·미니맵을 원하는 위치에 넣기(영상 위 또는 옆),
  전체 미리보기 후 저장

## Ver 0.1.1 — 2026-09-27
- 프로그램 이름을 **T6 Viewer**(Tesla dashcam smart viewer)로 변경, "T6" 글자를 렌즈 위에 얹은 새 아이콘(여러 크기 포함)
- 라이선스를 AGPL-3.0-or-later로 지정, 정보 창에 라이선스 전문 추가
- 저장 위치를 `%LOCALAPPDATA%\T6Viewer`, 영상별 분석 결과를 `.t6_viewer_cache`로 변경(예전 이름의 설정·분석 결과는 처음 실행 때 옮겨 씀)
- 다른 프로그램까지 포함한 PC 전체 메모리 사용량을 감시: 사용량 80% 이상이면 새 분석 프로세스를 띄우지 않고, 90% 이상이면 분석 프로세스를 줄이고, 95% 이상이면 미리 열기 해제·재생 속도 제한(페이지 파일 부족도 포함)
- 주행 정보 HUD를 Front 영상 바로 위에 배치, 브레이크 왼쪽·가속 오른쪽, 조향각·가속%·속도 글자 크게
- 지도를 내장 브라우저(Qt WebEngine)·Leaflet 대신 Qt로 직접 그리는 지도로 교체: 실행 파일 크기가 크게 줄고 인터넷의 스크립트(unpkg)를 받지 않음
- 브이월드 국내 지도 지원(설정에서 무료 API 키 입력), 키가 없으면 OpenStreetMap(시험용)
- 지도 타일을 디스크에 저장해 다시 받지 않음, 재생 중 위치 표시 갱신 비용 57 ms → 2 ms
- 주행 영상에서 속도·기어·조향·방향지시등·페달·G·주행 보조 상태를 그래픽으로 보여 주는 주행 정보 표시줄

## Ver 0.1.0 — 2026-09-27 (첫 공개 버전)
- TeslaCam 6채널(필러·전방·리피터·후방) 동시 재생, 한 채널 확대, 채널 선택
- 영상 끝에서 다음 영상으로 끊김 없이 이어 재생(다음 영상을 미리 열어 둠), 이전·다음 영상 버튼
- 1×~16× 배속과 가변 배속, 채널 수에 따른 배속 상한·영상 처음·끝 구간 8× 제한으로 메모리 안정화
- 앱 전체 메모리 4.5GB 한도 관리(분석 → 미리 열기 → 배속 순으로 줄임, 재생은 멈추지 않음)
- 주차·정차 영상의 객체 인식(사람·자동차·오토바이·자전거): 실제로 움직인 대상만 표시, 스킵·자동 스킵
- 썸네일, 20구간 스토리보드(준비되는 대로 표시, 백그라운드 생성)
- SEI 주행 정보(속도·기어·조향 등)와 지도 경로, 진행 방향 화살표
- 목록 열 제목 필터(일시·복호·폴더·주행·Event·분석), 분석 진행률 표시
- 여러 프로세스를 이용한 백그라운드 분석, 분석 범위·항목 설정
- Tesla 계정 키를 이용한 암호화 영상 로컬 복호화(토큰은 직접 입력, 저장하지 않음)
- 오픈소스 고지·라이선스 전문, 도움말, 설정·기록 일괄 삭제
- Pretendard 글꼴, 어두운 제목 표시줄, 앱 아이콘
